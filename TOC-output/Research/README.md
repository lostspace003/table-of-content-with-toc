# Research and Content Plans

Each course has its own research document in `TOC-output/<course>/Research/` (watermarked PDF, Word, Markdown and HTML). Each one covers where the course came from, how the outline was shaped, the lab environment, a module-by-module content plan (lessons, teaching points, demo, lab steps, pitfalls, knowledge checks, assets to prepare), the capstone, the research behind the promo video and a verified reference list.

Course outline

Device Health Monitoring Automation with Claude

From VIP, HA and version checks to the right ServiceNow ticket, automatically

3 days (8 hours per day) Intermediate Instructor-led, hands-on labs Capstone project

About this course

Who should attend

Network operations, load balancer and data centre engineers, NOC leads, ITSM and automation teams running F5, NetScaler, Radware, other load balancers (Anaya LB) and Cisco ACI.

Prerequisites

  • Working knowledge of load balancers (VIPs, pools, HA pairs, config sync)
  • Basic REST API and JSON concepts
  • Basic Python and Git
  • Familiarity with ServiceNow incidents and change requests is helpful, not required

What you will be able to do

  • Define a platform-neutral health model covering VIP status, uptime, HA state, sync state, version and last change for every device class
  • Collect health signals from F5 iControl REST and tmsh, Citrix NetScaler NITRO, Radware Alteon via Cyber Controller, other load balancers (Anaya LB) and Cisco APIC REST
  • Use Claude with tool use and structured JSON outputs to turn raw evidence into a cited, severity-ranked health verdict
  • Create or update ServiceNow incidents through the Table API and Flow Designer with deduplication and correlation IDs
  • Run the whole workflow on a schedule under approvals, guardrails and a complete audit trail

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.

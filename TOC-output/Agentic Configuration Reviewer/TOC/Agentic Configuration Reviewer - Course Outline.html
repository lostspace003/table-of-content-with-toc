Course outline

Agentic Configuration Reviewer

Review infrastructure and application configuration before deployment

2 days (8 hours per day) Intermediate Instructor-led, hands-on labs Capstone project

About this course

Who should attend

DevSecOps, platform and cloud engineers, infrastructure-as-code authors, security champions in engineering teams.

Prerequisites

  • Terraform or Kubernetes YAML basics
  • Git and pull-request workflow
  • Python fundamentals
  • Policy-as-code concepts are helpful

What you will be able to do

  • Parse and normalize Terraform plan output and Kubernetes YAML while preserving file, line and resource provenance
  • Combine deterministic policy rules with AI-assisted context and explanation
  • Generate minimal remediation diffs and validate them with native tooling
  • Integrate review results into a pull request as read-only comments that never auto-merge
  • Build a rule test suite and measure precision, missed cases and noisy alerts

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.

Course outline

Agentic Architecture Reviewer

Turn system designs into traceable threat models and security recommendations

3 days (8 hours per day) Advanced Instructor-led, hands-on labs Capstone project

About this course

Who should attend

Security architects, solution architects, application security, platform architects, engineering leads.

Prerequisites

  • System design fundamentals
  • Basic networking and identity concepts
  • Threat modeling (STRIDE or similar)
  • Python and API familiarity

What you will be able to do

  • Extract components, data flows, identities, external dependencies and trust boundaries from structured architecture inputs
  • Represent the system as a graph with provenance and uncertainty
  • Apply a repeatable threat-modeling method such as STRIDE to modeled components and flows
  • Generate architecture findings with evidence, assumptions, impact and recommendations
  • Compare intended design with selected implementation evidence without over-claiming verification

Capstone

Capstone project

A tool that ingests structured architecture inputs, builds a provenance-aware system graph, generates a linked threat model, produces evidence-graded findings and records architect decisions, with optional implementation cross-checks that report gaps rather than proof.

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.

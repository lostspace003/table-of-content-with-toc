Course outline

Automating IT and Network Operations with Claude

Eleven real operations workflows, rebuilt as supervised Claude agents

3 days (8 hours per day) Intermediate Instructor-led, hands-on labs Capstone project

About this course

Who should attend

Network engineers, load-balancer and ADC administrators, NOC and IT operations teams, DevOps and platform engineers, IT service desk leads.

Prerequisites

  • Working knowledge of enterprise networking and at least one load balancer (F5 BIG-IP, Citrix NetScaler or Radware)
  • Comfortable on the CLI and with REST APIs and JSON
  • Basic Python (reading and editing scripts); no prior AI or Claude experience required
  • A ServiceNow or similar ITSM instance and a GitHub account for the labs (lab tenants are provided)

What you will be able to do

  • Set up Claude Code, the Claude Agent SDK and Model Context Protocol (MCP) servers against a lab network
  • Design agent workflows where Claude plans and drafts, deterministic code executes, and humans approve
  • Automate certificate renewal, firmware upgrades, health checks and troubleshooting across F5, NetScaler and Radware devices
  • Generate change records, tickets, runbooks, bills and flow diagrams directly from live device and mailbox data
  • Ship Terraform and GitHub automation with reviews, tests, dry-runs, rollback and a full audit trail

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.

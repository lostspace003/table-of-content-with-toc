Agentic Virtual Patching Platform

From vulnerability finding to tested interim mitigation

3 days (8 hours per day) Intermediate to advanced Instructor-led, hands-on labs Capstone project

About this course

Who should attend

Application security, product security, DevSecOps, WAF and platform engineers, vulnerability management teams.

Prerequisites

  • Basic HTTP and web application security
  • Reverse proxy and WAF concepts
  • Python and container basics
  • Familiarity with an AI coding assistant is helpful, not required

What you will be able to do

  • Explain the role and limits of virtual patching as an interim mitigation, not a substitute for a permanent fix
  • Build a finding intake and evidence and context model with provenance
  • Generate candidate rules for a lab enforcement point using constrained templates and strict schemas
  • Create positive, negative, regression and bypass-oriented test cases and fail closed on incomplete validation
  • Produce an approval package with test evidence, rollback instructions and monitoring criteria

Capstone

Capstone project

A repeatable lab platform that ingests a finding, proposes an evidence-linked mitigation, validates it against target and benign traffic, and ships an approval package with tested rollback.

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.

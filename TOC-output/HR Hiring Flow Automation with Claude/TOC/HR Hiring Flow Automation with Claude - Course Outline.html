Course outline

HR Hiring Flow Automation with Claude

From portal filter to approved pitch, with a recruiter in control of every decision

3 days (8 hours per day) Intermediate Instructor-led, hands-on labs Capstone project

About this course

Who should attend

HR operations and talent acquisition teams, HR technology and enterprise IT automation engineers, and the network and platform teams that build and host these workflows in India and worldwide.

Prerequisites

  • Basic Python and the command line
  • Working knowledge of your organisation's hiring process and job portal exports
  • Familiarity with JSON and REST APIs
  • Familiarity with an AI coding assistant is helpful, not required

What you will be able to do

  • Map a real hiring flow from portal filtering to pitch and decide which steps a model may propose and which only a person may approve
  • Set up Claude Code, the Claude Agent SDK and an MCP server that exposes portal exports and a candidate store as tools with strict JSON outputs
  • Build a validated candidate profile pipeline that captures experience, location, salary ask and preferred working hours with unknowns marked, never guessed
  • Automate call preparation, scheduling and consented recording through Twilio Programmable Voice, and score English proficiency and fit from transcripts with cited evidence
  • Ship an approval-gated pitch generator delivered by email with PII minimisation, consent tracking, prompt injection defences, fairness checks, an append-only audit log and a ServiceNow onboarding handoff

  • Claude extracts fields from resume text into the schema with a confidence per field; unknowns are marked, never guessed
  • Treating resume text as untrusted input: tool-free extraction, schema validation and rejection of out-of-schema content
  • Human review queue for low-confidence fields

Module 5Calling candidates: scripts, scheduling and consented recording

Module 6Assessing English proficiency, experience, location, salary ask and hours

  • Deterministic checks for experience years, location, preferred working hours against the shift, and salary ask against the approved band

Hands-on labScore twenty synthetic transcripts, compare against two human raters and tune the rubric until agreement is acceptable.

Module 7Pitching the role: drafts within approved talking points

  • Objection handling notes for the recruiter, never automated negotiation
Hands-on labGenerate pitches for the top ten candidates, prove the generator refuses an out-of-band salary, and route each draft through approval.

Engineering principles used throughout

  • Model output is a proposal, not a fact: every finding and generated change is validated by deterministic checks and tests.
  • Authorization lives outside the model: tool access is enforced by application code, scoped credentials and policy.
  • Human approval for consequential actions: deploying a mitigation, changing production configuration, rotating credentials.
  • Decisions, evidence, model and tool versions, approvals and outcomes are logged without recording secrets.
  • A model adapter and a tool adapter layer keep every build provider-agnostic and enterprise-portable.
  • Quality is measured: false positives, false negatives, reliability, latency, cost and safe failure, not just a demo.
